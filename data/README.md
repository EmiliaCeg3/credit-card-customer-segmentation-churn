# Dataset

## Source

The dataset used in this project was obtained from Kaggle under the name **"Predicting Credit Card Customer Attrition"**.

The dataset is attributed to:

> zhyli. (2020). *Prediction of Churning Credit Card Customers* [Data set]. Zenodo. https://doi.org/10.5281/zenodo.4322342

## Dataset overview

The dataset contains information on **10,127 credit card customers**.

It includes:

* **20 analytical variables** used to describe customers and their relationship with the bank,
* **1 identifier** (`CLIENTNUM`),
* **1 target variable** (`Attrition_Flag`).

Each observation represents a single credit card customer.

### Identifier

`CLIENTNUM` is a unique identifier assigned to each customer in the bank's system. It was used only to identify individual records and was not included as an analytical variable or model feature.

## Data preprocessing

The original data file contained two additional columns representing predictions generated by a Naive Bayes classifier.
Following the recommendations provided with the dataset, these columns were removed before conducting the analyses. This prevented pre-existing model predictions from being used as input variables and helped avoid information leakage.

Further preprocessing and feature engineering were performed as part of the analytical pipeline. These steps are described separately in the project methodology and notebooks.

## Target variable

The target variable is `Attrition_Flag`, which indicates whether a customer has left the bank.

For the churn prediction task, it was transformed into a binary representation:

* `1` — `Attrited Customer` (customer churned)
* `0` — `Existing Customer` (customer remained with the bank)
